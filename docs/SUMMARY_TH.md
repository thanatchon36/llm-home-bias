# สรุปภาษาไทย (10 บรรทัด)

1. คำถาม: LLM แบบ open-weight แนะนำให้ลงทุนในตลาดหุ้นของประเทศผู้พัฒนาโมเดลมากกว่าที่โมเดลจากประเทศอื่นแนะนำหรือไม่ (home bias ของโมเดล)
2. ออกแบบ: ทดสอบ 12 โมเดลจากจีน สหรัฐฯ ยุโรป ไทย และเกาหลี รันบนเครื่องผ่าน Ollama (4-bit) โดยทุกโมเดลตอบ 240 prompt ชุดเดียวกัน
3. แต่ละ prompt ขอให้แบ่งพอร์ต 100 แต้มลงตลาดหุ้น 8 แห่ง โดยสุ่มสลับลำดับในเมนู และไขว้ปัจจัยสัญชาติผู้ลงทุน × ภาษา (อังกฤษ/จีน/ฝรั่งเศส/ไทย) × ความเสี่ยง × ระยะเวลา
4. ลงทะเบียนแผนวิเคราะห์ (PAP) และค่า hash ของชุด prompt ไว้ก่อนรันจริง และแก้แผนครั้งเดียว (A1) หลัง pilot ก่อนรันเต็ม
5. ผลหลัก: H1 ไม่ได้รับการสนับสนุน — ตลาดบ้านเกิดได้น้ำหนัก −0.42 pp เทียบกับที่โมเดลอื่นให้ (95% CI −0.59 ถึง −0.25) ขณะที่ถ้าแบ่งเท่ากันจะได้ตลาดละ 12.5 pp
6. ผลรายโมเดลกระจายตั้งแต่ −3.5 ถึง +1.9 pp โดยไม่มีแบบแผนตามประเทศ และเมื่อปรับเรื่องที่บางโมเดลแบ่งเกือบเท่ากันทุกตลาด (post hoc) ได้ +0.12 pp คือไม่มี home bias
7. สิ่งที่ผู้ใช้บอกมีผลมากกว่า: ถ้าระบุว่าผู้ลงทุนอยู่ประเทศใด ตลาดนั้นได้เพิ่ม +1.88 pp (ราว 4.4 เท่าของผลจากประเทศผู้พัฒนา) ส่วนภาษาของ prompt เพิ่ม +0.46 pp
8. Fine-tune ภาษาไทยให้ผลสองทาง: OpenThaiGPT ให้ไทยมากกว่า Qwen2.5 ซึ่งเป็นฐาน +1.26 pp แต่ Typhoon2 ให้ไทยน้อยกว่า Llama-3.1 ซึ่งเป็นฐาน −1.04 pp
9. ทุกโมเดลเลือกถือเงินสดเป็น USD 80–97% ของคำตอบ และให้น้ำหนักสหรัฐฯ เพียง 8–23% (MSCI ACWI ราว 75%) คือใกล้การแบ่งเท่ากันมากกว่าตาม market cap
10. ข้อจำกัด: เป็นโมเดลเล็กแบบ 4-bit, ใช้เครื่องมือวัดชุดเดียว และใช้ greedy decoding ผลนี้บอกพฤติกรรมของ output ไม่ได้บอกเจตนาหรือข้อมูลที่ใช้ฝึก
